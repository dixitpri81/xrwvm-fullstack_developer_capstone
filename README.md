# Full-Stack Development Capstone — Car Dealership

## Repository
**Repository Name:** xrwvm-fullstack_developer_capstone

## Project Name
**Project:** Cars Dealership Web Application

## Description
A full-stack web application built for a national car dealership chain operating across the United States. The application allows users to browse dealership branches by state, view dealer details, read customer reviews, and submit their own reviews after logging in.

## Technologies Used
- **Frontend:** React.js, HTML, CSS, Bootstrap
- **Backend:** Django, Python
- **Database:** SQLite, MongoDB
- **Sentiment Analysis:** Watson NLP
- **Deployment:** IBM Cloud Code Engine
- **CI/CD:** GitHub Actions
- **Containerization:** Docker, Kubernetes

## Features
- Browse all dealership locations across the US
- Filter dealerships by state
- View dealer details and customer reviews
- Register and log in as a user
- Submit reviews with sentiment analysis
- Admin panel for managing content
